# 申请材料清单

按「要交什么、什么格式、谁盖章」核对。各校网申要求不同，最终以申请系统为准。扫描件统一用 PDF。

中英文成绩单、均分证明、在读证明，都要先盖学校 / 教务处的章，再扫描。英文毕业证、学位证同样：原件直接扫，英文版盖章后再扫。

## 1. 护照

- 扫护照**内页首页**（个人信息页），不要扫封皮。
- 还没办护照：尽快去办。过渡期可先交**中英文**身份证正反面 PDF。
- 出入境记录页也要扫；申请学校交一次，办学生签证再交一次。详见 [踩坑：护照扫描件](10-踩坑合集.md#pit-passport)。

## 2. 语言成绩

- 已考雅思：交成绩单 PDF。
- 还没考：这项可先空着。

## 3. 成绩单与在读证明

- 本科完整**中英文成绩单**（须含中英文评分标准）。
- 成绩单上如果没有均分 / 绩点：另开一份**中英文均分证明**，打印在学校抬头信纸上，落款盖章。
- 在读：至少提供 **6 个学期**的中英文成绩单（含评分标准），外加中英文在读证明。
- 某些大学要求较严格，成绩单上若有补考记录：还得到教务处另开这几门课的**原始成绩**中英文说明，并加盖教务处公章。
- 本校若不直接开英文成绩单，需先翻译再拿回教务处盖章。详见 [踩坑：英文成绩单翻译盖章](10-踩坑合集.md#pit-transcript)。

## 4. 毕业证与学位证（仅已毕业）

- 本科毕业证：中文原件扫描 + 英文翻译件 / 公证件（英文版盖学校 / 教务处章后再扫）。
- 本科学位证：同上。
- 在读学生不交这两项。

## 5. 工作 / 实习证明

- 中英文 PDF。
- 用公司抬头纸打印并盖章。没有相关经历可先空着。

## 6. 简历采集与申请费

- 按中介或申请系统要求，填完整份简历信息采集表。
- 办一张 Visa 或万事达双币信用卡，并开通境外网上支付，用来交网申申请费。

## 纸质邮寄

- 主要是**申请澳洲**学校：除了网申上传 PDF，还可能要求**中英文纸质件**邮寄。
- 建议用**国际快递**，不要用普通信件；贵但可追踪，丢件能找回来。
- 推荐信等信封封口的纸质件，**不要提前拆封**，寄出前跟学校确认投递方式。

## 推荐信：哪些国家要，找谁写

### 哪些国家需要推荐信

- **一般不需要**：澳洲、新西兰。授课型硕士申请通常不要求提供推荐信。
- **一般需要**：英国、爱尔兰、美国。申请时通常需要提供推荐信（常见为 2 封）。

### 找谁写（看你的本科背景）

- 本科是**一般学校**：找跟你关系好、真正了解你的老师写就行。内容写得具体、真实，比老师的头衔重要。
- 本科是**世界名校**：可以考虑请业内知名的老师写。顶尖学校的审核里，推荐人的分量是加分项。

### 提醒

- 以上是一般情况，个别项目或奖学金申请可能有额外要求，递交前务必对照目标学校官网的材料清单逐项核对。
- 推荐信要预留时间，提前跟老师打招呼，别拖到 deadline 前一周才开口。
