# 网申与提交

按「账号 → 填表 → 上传 → 缴费 → 跟进」记录操作要点。字段名称以实际申请系统为准。

## 申请系统与账号

记录使用的系统名称、注册邮箱、双因素验证、与学校门户是否同一账号。

## 填表逐项注意

记录姓名拼写、学历日期、GPA 计算方式、地址格式等易错字段。

> 待补充

## 上传材料格式要求

记录文件类型、大小上限、是否合并 PDF、扫描清晰度。

> 待补充

## 申请费与支付

记录费用是否可退、可用支付方式、账单姓名与护照是否一致。金额以系统显示为准，此处不写数字。

## 提交后如何跟进

记录状态页查看频率、补件邮件如何处理、推荐信是否到齐。
