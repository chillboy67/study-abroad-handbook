# 踩坑合集


记录「坑」，没有内容时保持待补充。


<a id="pit-transcript"></a>
## 条目 1


**坑**


> 部分学校并不会主动开具英文版成绩单，需要自己找留学中介 / 申请院校认可的翻译机构 / 公证处 /（部分情况可在闲鱼淘宝联系专门的商家进行翻译，对自己英文翻译水平满意的同样可以自己翻译，但存在一定风险）出具英文翻译件，再拿回教务处加盖公章才算有效。


<a id="pit-passport"></a>
## 条目 2


**坑**


> 提交护照扫描件时，要扫的是护照内页首页（个人信息页），不是封皮；有出入境记录的页面也要一并扫上。申请学校时提交一次，办理学生签证时再提交一次。两次之间如果出过国，不影响学校申请；但办学生签证时，需要把新的出入境记录页补扫后再交。


<a id="pit-agent-au"></a>
## 条目 3


**坑**


> 申澳洲新西兰的授课硕，不要文书、不要推荐信，有些连申请费都不收——这种申请自己 DIY 完全搞得定。我当时找了中介，申请这部分的中介费花得不值。但签证、体检这些环节，有中介盯着还是省心（存款证明的存期、体检名额，都有硬性时间要求）。只申澳新的话，可以申请 DIY、签证阶段再找中介做单项。


<a id="pit-housing"></a>
## 条目 4


**坑**


> 以为中介"全包"连房子都会帮忙找，结果找房得自己来。签合同前问清服务边界，"全包"包到哪一步写进合同。拿到 offer 就可以开始看房，别等签证下来。
