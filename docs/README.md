# 留学申请手册 · 文档目录

本目录是申请过程的章节骨架。各页只提供结构与待填占位，具体内容按个人进度补写。政策、截止日期、材料要求一律以官方最新公告为准。

## 章节

- [时间线与规划](01-时间线与规划.md) — 从提前准备到申请季节点的时间安排。
- [申请材料清单](02-申请材料清单.md) — 成绩单、语言、PS、推荐信等到递交前的材料核对。
- [语言考试](03-语言考试.md) — 考试选择、报名、送分与成绩有效期。
- [选校与专业](04-选校与专业.md) — 冲稳保分层、转专业可行性与课程阅读方法。
- [网申与提交](05-网申与提交.md) — 账号、填表、上传格式、申请费与提交后跟进。
- [录取与押金](06-录取与押金.md) — Offer 条件、押金截止、换 offer 与退费风险。
- [签证与体检](07-签证与体检.md) — 签证材料、资金证明、体检与递交审理。
- [行前准备](08-行前准备.md) — 机票住宿、保险、行李与落地第一周。
- [费用清单](09-费用清单.md) — 申请费、学费、生活费与记账模板。
- [踩坑合集](10-踩坑合集.md) — 按「坑 → 后果 → 正确做法」汇总已踩过的问题。
