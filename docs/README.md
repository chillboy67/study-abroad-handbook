# 留学申请手册 · 文档目录

本目录是申请过程的章节骨架。各页只提供结构与待填占位，具体内容按个人进度补写。政策、截止日期、材料要求一律以官方最新公告为准。

## 章节

- [时间线与规划](01-时间线与规划.md) — 从提前准备到申请季节点的时间安排。
- [申请材料清单](02-申请材料清单.md) — 成绩单、语言、PS、推荐信等到递交前的材料核对。
- [选校与专业](04-选校与专业.md) — 冲稳保分层、转专业可行性与课程阅读方法。
- [踩坑合集](10-踩坑合集.md) — 按「坑 → 后果 → 正确做法」汇总已踩过的问题。

## 可复制模板

- [踩坑记录单条模板](_模板-踩坑记录.md) — 复制后填写一条完整记录。
